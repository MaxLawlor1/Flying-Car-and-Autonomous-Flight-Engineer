## Projects

Each project is included in its own subfolder. Information about each project can be found below:

### Backyard Flyer

This repository contains my implementation of the **Backyard Flyer** project from the Udacity **Flying Car and Autonomous Flight Engineer Nanodegree**.

#### Project Overview

The goal of this project is to build a simple drone state machine that can:

- arm the drone
- take off to a target altitude
- fly a box-shaped set of waypoints
- land
- disarm and return control

This project helped me practice:

- event-driven drone control
- state machine design
- waypoint navigation
- working with the Udacity drone simulator and `udacidrone` API

#### Files

- `backyard_flyer.py` — main project script containing the drone state machine
- `README.md` — project description and notes

#### How to Run

1. Start the Udacity simulator.
2. Run the project script:

```bash
python backyard_flyer.py
```
